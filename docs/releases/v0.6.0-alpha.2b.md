# Alpha 2b: USA Is Back on the Guest List

Small packaging fix, same excessive grass.

- Restores USA ROM import and equivalent EUR/USA dump recognition accidentally
  omitted from alpha.2, on **both Windows and Linux**.
- Adds a release audit that rejects packages missing these qualified input
  contracts. A matching Program ID alone is still not enough: Forge checks the
  actual decrypted content.
- Keeps the tested alpha.2 game, Forge, renderer and bundled shader preparation
  unchanged. No compiler or SDK is needed, and no new Flatseal permissions are
  required to fix this particular rejection.

Use your own decrypted EUR/USA `.3ds` or `.cci` dump. If alpha.2 rejected it,
update and run Forge again. Windows users should extract into a fresh folder;
keep the previous installation and back up saves/settings before moving data.
Linux users can install this Flatpak over the previous version; application
data remains outside the package.

Verified with real frozen Forge installations and 300-presentation intro runs
on Windows and Linux, including a logically equivalent repacked USA input on
Linux. This is not a full-game compatibility claim; physical Steam Deck testing
is still outstanding. Unrelated Windows loader failures remain under investigation.

The packages retain the exact corresponding source for their unchanged alpha.2
binaries (source freeze `72e4c37`). The input-coverage correction is `b1702ea`,
with verification recorded in `fb8161c` and this release's tagged source.
