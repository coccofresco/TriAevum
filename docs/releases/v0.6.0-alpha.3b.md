# TriAevum v0.6.0-alpha.3b

## Start Means Start

- Fixed **#48**: pressing Start during the title sequence no longer ends your
  adventure before the save menu. An ambitious speedrun category, now retired.
- The same renderer composition fix is included on **Windows and Linux**.
- Everything else from alpha.3 stays: TopScreen, HD fonts, configurable graphics,
  and an entirely unreasonable quantity of grass. Save formats are unchanged.

Windows: portable ZIP. Linux: AppImage. Back up saves/settings before updating;
prefer normal game saves over savestates made during Sheik's revelation flashback.
Steam Deck remains a compatibility target, not a hardware-tested certification.

**Sion / 999sian** for their PR contributions, and **Ship of Harkinian, Azahar,
NRI** and the other donor projects.
