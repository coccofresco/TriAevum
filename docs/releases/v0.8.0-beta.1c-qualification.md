# Beta.1c Release Qualification

Date: 2026-10-15. Scope: Windows x64 portable ZIP, Linux x86-64 AppImage and
Linux x86-64 Flatpak bundle (candidate r12). A Linux hotfix of
[beta.1b](v0.8.0-beta.1b-qualification.md); everything not listed here is as
qualified there.

## Source and Package Boundaries

- Runtime/source freeze: `604c2918d46c15f8558fa5ed859fe54cebfc5219`
  (branch `release/0.8.0-beta.1b`). The release tag may also include this
  subsequent documentation-only record.
- The only runtime change since beta.1b is `ccd0f47`: the default save-state
  folder stays next to `TriAevum.exe` in the portable Windows layout and, on
  Linux, moves beside the save data (`data/savedata` -> `data/savestates`),
  because the AppImage and the Flatpak run from a read-only image (#61).
- All packages pass the allowlist/hash/source audit with no errors. Windows
  contains 84 catalogued files; Linux contains 575, as in beta.1b. Title
  module, DLSS module and MXAO library are byte-identical to beta.1b.

## Checks Performed

- Release tooling: 499 tests, 13 explicitly skipped, no failures.
- `oot3d_native_a32_savestate_tests` on Windows and in the Steam Runtime 4
  SDK, with new cases for the default folder.
- Defect reproduction: the published beta.1b Flatpak failed a save state with
  "Save state failed: cannot create the folder (Read-only file system)".
  The fixed runtime in a read-only copy of the AppDir saved to
  `TriAevum/data/savestates`.
- Clean-Windows script on the final ZIP, frozen Forge install worker, no SDK
  on PATH:

  | Input | Forge install | Boot | Guest draws | First-launch benchmark |
  | --- | --- | --- | --- | --- |
  | EUR (private dump) | 75.1 s | 1,200 frames, exit 0 | 42,823 | 53.1 FPS |
  | USA Rev 1 (No-Intro 1259) | 72.9 s | 1,200 frames, exit 0 | 42,544 | 53.3 FPS |

  The installed EUR package reached the file select with the
  title-to-file-select timeline, and a save state from it was written to
  `savestates` next to `TriAevum.exe`, as before.
- Linux reference machine (KDE Wayland, GeForce RTX 4060): the runtime was
  rebuilt incrementally after a CMake reconfigure, packaged, audited and
  bundled as a Flatpak (OSTree commit
  `9837c329437ce7910bc5eb27f43a1a6c98953af60b689b2299053f89fb217286`). The
  AppImage runtime and the Flatpak, installed over beta.1b in the isolated
  user installation, each booted 1,800 frames over the existing data with
  the title-to-file-select timeline and a save state at frame 1,700: 57.4
  and 56.3 FPS, 37,002 and 37,074 guest draws, exit zero, no pending draws,
  file select captured, and one new state in `data/savestates` each.
