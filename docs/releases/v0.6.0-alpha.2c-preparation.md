## Source and Package Boundary

Both runtime executables were built from source freeze
`293aff80ecfcdca4a526e9e5e4663ae490f5f2b4`. Their product information reports this
exact commit. The corresponding source archive contains 3,418 files; SHA256
`e282f25b7feb02f25ce8258e8a74e8d79eeb0024e5767a4dc55b97c3dd1bb990`.
The release tag includes later qualification documentation; it does not identify
a second runtime build.

Each package was assembled from the alpha.2b explicit inventory, after checking
every original file hash. Exactly four payload paths changed: the runtime,
`recipes/precompiled-titles.json`, `source/TriAevum-source.zip`, and the newly
added alpha.2c notes. The generated release manifest records the new version,
runtime identity and hashes. The title module, native module, Forge, shader
corpus, shader preparation helpers, dependencies and input contracts are
byte-identical to alpha.2b. Frozen Forge/helpers retain their alpha.2 provenance
(`72e4c37`); no title AOT rebuild occurred.

Mandatory release audits passed: 61 Windows files and 521 Linux files. The
`candidate` qualification is intentionally retained, as in alpha.2b: the broad
clean-external-Windows-machine qualification is still outstanding. This is an
authorized experimental prerelease, not a claim that every readiness gate or
physical Steam Deck scenario is complete. No audit or content check was disabled.

## Verification

- Windows actual packaged Forge prepared the local EUR input in 13.86 seconds,
  with zero compiled title objects. The resulting installation ran the complete
  display matrix: exit 0, 1,322 frames, modes 0/1/2, eight applies, one rollback,
  zero apply failures and zero GPU validation errors (validation enabled).
- Linux actual frozen Forge inside the new Flatpak prepared the previously
  qualified USA repack in 24.91 seconds, with zero compiled title objects. Its
  initial 300-frame intro exited 0 with zero whole-AOT memory faults.
- Linux final Flatpak minimized/restored twice through real XWayland window
  actions, exited 0 and resumed rendering. Its separate display matrix exited 0
  with 1,852 frames, eight applies, one rollback and zero apply failures. Reported
  GPU error counters were zero; Vulkan validation layers were not requested.
- Both matrices were checked using `probe_display.verify`, including complete
  frame histories and every scheduled action. Runtime framebuffer captures were
  visually inspected. Test runs are not FPS benchmarks.
- Earlier fix qualification additionally covered 24 rapid requests, F11 with
  F1 open, injected transaction failures and a suspended-clock regression.
  See [the lifecycle report](../TRIAEVUM_FULLSCREEN_LIFECYCLE.md).
- 41 targeted Python tests passed (display, package update, precompiled release,
  input coverage, source archive and Flatpak). The first invocation had four
  import errors; rerunning with the documented tools directory on PYTHONPATH
  passed. No source correction was needed for those invocation errors.
- Every file was rehashed from the final Windows ZIP; no unlisted files.
  Linux payload files were rehashed after staging. The existing launcher and
  portal chooser remain byte-identical. The Flatpak bundle imported into a new
  empty OSTree repository with commit
  `3c713d31f91adf6c00a681ee0f766ef201368090177f77ebb5ef95fdffbc857a`.

No ROMs, keys, game-derived data, saves, captures, device caches or private
diagnostic scripts are shipped. Preserve existing saves/settings when updating.
Steam Deck hardware, monitor unplug/migration and arbitrary GPU device loss are
not covered. NRI's recovered OUT_OF_DATE messages during minimization are not
hidden or claimed to be absent.
