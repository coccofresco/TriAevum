## Source and Package Boundaries

- Rehearsal cut: `8d7fc0f35de96421004e7bf14d4a885b5cc77488` (branch
  `release/0.8.0-beta.2`), the same commit as the Moonfall Curse alpha-1
  candidate base. The final cut is a later commit: it reverts the D4 change
  `e20d0b63` for interactive play (the transient uber program is accepted for
  fluidity; fixed-step sessions stay bit-exact) and adds the publisher's
  update-signing key. Neither touches a shader-corpus decision-policy input,
  so the recordings of this cut stay valid; the runtime bytes change, so the
  release build, the identity receipt and the package steps are repeated at
  the final cut.
- Changes since beta.1.2 (`a56f964`): 560 commits (shared engine, Forge and
  release tooling, the second title's adapter); the user-visible ones are in
  the change matrix below.
- **Linux Forge build requirement (release review G3-F2):** the Linux Forge
  must be built from a tree that contains `9972f28d` (the `-ffile-prefix-map`
  remap of C and assembly source paths of the cc-built crates). A Linux Forge
  built from a tree without it, with debug line tables, carries build-machine
  paths and fails the path gate of `stage_linux_forge_candidate.py`. If the
  per-title Linux staging is used, `b6e409dd` and `821deccd` are required with
  it. Check: `git merge-base --is-ancestor 9972f28d <cut>` (true at
  `8d7fc0f3`), then the `c_flags` cases of `test_title_release.py` and the
  path gate on the Linux build receipt.
- Signing: the rehearsal package is a candidate (unsigned); beta.2 is planned
  as the first signed release (key added at the final cut, see
  `docs/TRIAEVUM_UPDATE_SIGNING.md`).
- Title module: the OoT3D whole-AOT title inputs changed since beta.1.2
  (generator, pinned A32 runtime, Forge source and plugin backends), so the
  module was regenerated and rebuilt with the beta.1.2 PGO profile
  (`431da79d…`). The generated C++ is byte-identical to beta.1.2's translated
  title source (259 of 259 common files; only the generation manifest and its
  key differ), the structural program is `08696784…` as before; the plugin
  differs because the runtime support library changed.
- Package audit: (final cut).

## Enhanced Shader Corpus

The beta.1.2 corpus is not qualified for this cut: against the beta.1.2
qualification record, 169 of its 264 generator inputs and 327 of the 469
decision-policy inputs of each of its ten recordings changed. Everything is
recorded again at the cut, on the same plan as beta.1.2: the Better-scene
sweep for scenes 0-11 on Windows and 12-48 on the Linux AMD reference machine
(developer builds of the cut, reduced visit list), the event sessions
(Barinade and Kokiri storms under both profiles, a game over, a cutscene) and
the boot to the file select under both profiles. The product profile is
regenerated from the cut's default settings (it gains 4x anisotropic
