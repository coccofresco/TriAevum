# Alpha 2b Qualification

Date: 2026-09-12. Metadata-only maintenance prerelease for Windows and Linux.

## Scope and Provenance

The publisher reconstructs each package from alpha.2's explicit release inventory,
verifies every original hash, then applies `qualified_input_coverage.build_overlay`.
Every resulting input contract must be byte-identical to the candidate exercised
with actual frozen Forge and an intro run. No development installation is copied
wholesale. New package inventories pass the current release audit.

Exactly four payload files differ from alpha.2: `recipes/oot3d.json`,
`recipes/precompiled-titles.json`, the restored
`recipes/adapters/oot3d-usa-ef210566-copies.json`, and alpha.2b release notes.
The generated release manifest additionally records the new version and hashes.
All runtime, Forge, title, dependencies, source archives and shader corpus bytes
remain unchanged. Binary source freeze remains
`72e4c37f8ce068349e007947ea2f27a3324a0c7f`; do not claim rebuilt binaries from the
new tag. The tagged public source contains the publisher corrections.

Packages retain the conservative `candidate` machine qualification because this
is a targeted real-install/intro qualification, not a claim that every broad
readiness gate or physical Steam Deck test is complete. Maintainer authorized
publication as an experimental prerelease.

## Checks

- 390 local tests, 14 expected skips. GitHub runs `34698896853` and `34698896711`
  pass the complete release-policy workflows for the corrected source.
- Windows real frozen Forge accepts the USA input; Linux real frozen Forge also
  accepts a logically equivalent USA repack with different container hashes.
  Both activate without title compilation and retain 588 GPU pipeline recipes.
- Both resulting installations complete 300 intro presentations with exit 0,
  zero whole-AOT memory faults and inspected framebuffer captures. Detailed
  timings and limitations: [input-coverage regression](../TRIAEVUM_ALPHA2_INPUT_COVERAGE_REGRESSION.md).
- Windows final ZIP: all 60 inventoried files rehashed from the archive; no
  additional files. Linux package: 520 audited files, each rechecked after staging.
- Flatpak launcher and portal chooser remain byte-identical to qualified alpha.2.
  The Flathub runtime-repository reference is included. Final bundle imported
  successfully into a new empty OSTree repository and reproduced application
  commit `fb6ac3508932395fc218e7589f5aede1a6f266e2130e2b62ec5ff19823e1c8e3`.
- No ROMs, saves, diagnostic captures, mod archives or device GPU caches included.
- Windows issue #12's missing DLL export is separate and is not claimed fixed.
