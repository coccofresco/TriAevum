## Publication Boundary

The maintainer has requested the portable shader corpus for all Forge users.
The automatic permission reviewer nevertheless rejected the attempted audit
change because the supplied AGENTS invariant still categorically forbids
game-derived shader-cache payloads in public packages. No patch was applied
and no alternate execution path was used to bypass that rejection.

The maintainer subsequently explicitly confirmed the amendment: allow only the
catalogued portable shader programs and observed pipeline recipes, not GPU
driver caches, ROMs, extracted assets, saves, captures or mod archives. The
exception is represented in the publisher and its audit, not hidden in
the frozen executable. A runtime cache belongs to each user's installation.

## Remaining Publication Steps

The package metadata intentionally remains `candidate`: clean-machine Windows
qualification and physical Steam Deck/Gaming Mode testing are not claimed.
The Linux package has no AppStream listing or custom exported application icon
yet; it is a directly installable GitHub Flatpak, not a Flathub submission.
Full playthrough and complete shader coverage remain out of scope for this alpha.

The maintainer explicitly authorized publication. Exactly three assets were
uploaded: the Windows ZIP, Linux Flatpak and SHA256SUMS.txt. GitHub's asset
digests were checked against the local files before publishing. The tag and
source branch were pushed without rewriting existing history. README download
links now point to alpha.2; all alpha qualification limitations above remain.
