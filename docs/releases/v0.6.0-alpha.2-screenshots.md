# Alpha.2 promotional screenshots

Published on 2026-09-12 with explicit maintainer authorization for three
promotional images in the README and release notes. This narrow exception does
not authorize packaging diagnostic captures, dumps or savestates. The Windows
ZIP and Linux Flatpak are unchanged.

All images are direct framebuffer captures from the qualified alpha.2 binaries,
converted losslessly from BMP to PNG at the original 1280 x 720 resolution.
No cropping, color correction, image generation or desktop capture was used.
Settings come from the packaged default profile, including TopScreen.

| Published image | Source |
| --- | --- |
| alpha2-kokiri.png | Windows portable release, native Kokiri transition, frame 600 |
| alpha2-title.png | Windows portable release, intro frame 540 |
| alpha2-mounted-linux.png | Linux Flatpak payload, mounted gameplay verification, frame 150 |

These illustrate appearance, not performance or full-game coverage.
The Linux image is not a physical Steam Deck capture.

At the maintainer's request, the dark Hyrule view was replaced with Kokiri.
The same Windows release was used with the existing structural scenario
`spot04_info_entry_0211`, which requests the game's native entrance 529.
The transition completed successfully; graphics settings were unchanged.
