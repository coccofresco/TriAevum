### The game has a name now

- **`TriAevum.exe` is now `Echoes_of_Time.exe`.** Forge installs the game under
  the product name, names its launch profile after it
  (`Echoes_of_Time.launch.json`) and removes the old `TriAevum.exe` from the
  installation folder, so a shortcut to the old file stops working: point it at
  `Echoes_of_Time.exe` (or start the game from Forge). Forge itself keeps its
  name, `TriAevumForge.exe`.
- **Linux** installs the game binary as `Echoes_of_Time` too; the AppImage and
  the Flatpak start it for you as before.
- **Updating in place from beta.1.2 works.** Extract beta.2 anywhere and run its
  Forge against your old folder (`TriAevumForge.exe --update-target <old
  folder>`, see `docs/TRIAEVUM_UPDATE_SIGNING.md`). Your saves, save states,
  settings, texture packs and launch options stay as they are; the old
  `TriAevum.exe` is replaced by `Echoes_of_Time.exe`.
- **Save states moved into the data folder** (`data/savestates`). Existing save
  states are migrated on the first start and load from the new place.
- **Forge is built per game.** The Forge in this package prepares Ocarina of
  Time 3D only.

### Graphics

- **Anisotropic texture filtering**, 4x in the Enhanced preset: floors and
  walls at a grazing angle stay sharp instead of melting into the distance.
- **HD texture replacements get their own mip chain** (#122): distant HD
  textures no longer shimmer or fall back to the wrong size.
- **Lighting fixes**: outdoor rooms with fixed light settings keep their own
  light, and filter-blended draws (water surfaces among them) keep the game's
  own appearance.
- **Renderer and grass work**: leaner draw preparation, fewer allocations per
  frame, and grass selection on the GPU that tests only what is in view.
  Shared engine work for the second title also landed in the renderer; the
  release is checked against beta.1.2 so that Ocarina of Time 3D looks the same
  except where listed here.
- **AMD on Windows**: the driver gets robust pipelines and a device-loss report
  that names what failed.

### Menus, controls and diagnostics

- **The Esc / R3 menu is sized for any screen**, the game pauses behind it,
  and master volume and mute have one control. A stuck mouse pointer no longer
  swallows keyboard and controller input in the menu's dialogs, and a settings
  write that fails is reported instead of claimed.
- **Controller rumble** on damage and other game events, on pads that have it.
- **Input device log**: the log lists the connected pads and the keyboard for
  support reports, without serial numbers or your user name.
- **A fatal error ends the game promptly** with its error dialog instead of
  hanging while shaders are still being prepared.
- Button prompt glyphs follow your pad in the menu footer and help card.
