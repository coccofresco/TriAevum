# TriAevum v0.6.0-alpha.2

## More Hyrule, less housekeeping

The renderer obsession continues. This time, a little more attention went to
the part where you actually play the game.

Special thanks to **Sion ([999sian](https://github.com/999sian))** for the Linux
foundation ([#6](https://github.com/coccofresco/TriAevum/pull/6)), display feedback
([#14](https://github.com/coccofresco/TriAevum/pull/14)), and contributions informing
shader preparation ([#11](https://github.com/coccofresco/TriAevum/pull/11)) and
TopScreen fixes ([#13](https://github.com/coccofresco/TriAevum/pull/13),
[#18](https://github.com/coccofresco/TriAevum/pull/18)). These were selectively
integrated or adapted, not blindly merged. Thanks also to
[Pablo Souza](https://github.com/PabloVSouza) for the capture work from
[#16](https://github.com/coccofresco/TriAevum/pull/16).

- **Linux joins the party.** One Flatpak for Linux desktops and the Steam Deck
  target, with Forge included. Windows stays portable: unzip, prepare, play.
- **Forge does more homework.** The bundled shader corpus is prepared
  automatically for your GPU during setup. No extra files to choose; missing
  variants are still learned and cached while playing.
- **Grass has learned some restraint.** Adaptive clusters, better distant
  coverage, and closer matching to the terrain's color and lighting. Still grass.
  Just less determined to occupy your entire GPU.
- **TopScreen gets a tune-up.** Fixes for item slots, ocarina guidance, HUD
  flickering, mounted layouts, minimap markers and ammunition placement.
- **Fewer arguments with the controls.** A clearer F1 binding interface,
  press-to-bind controls, and fixes for mouse aiming and camera recapture.
- **Less window wrestling.** Resolution/fullscreen fixes, clearer display-error
  feedback, ROM-aware language selection in Forge and F1, and Linux presentation
  and shutdown fixes.

Still an alpha, not a full-playthrough certification. Steam Deck hardware and
Gaming Mode have not been tested directly. Android is not part of this release.
Shader coverage is not complete, and first encounters can still compile shaders.
60/90 FPS modes interpolate presentation; game simulation remains at 30 Hz.

Use your own decrypted EUR or USA dump in `.cci` or `.3ds` format. On Windows,
extract the entire ZIP to a writable folder and run `TriAevumForge.exe`. On
Linux, install the Flatpak and open TriAevum; Forge handles the first setup.
For the Steam Deck target, prepare in Desktop Mode before adding it to Steam.
Back up saves and settings before updating. F1 configures the renderer; F2
temporarily disables the main graphical additions without discarding settings.
