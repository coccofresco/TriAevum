# Vanilla+ - Link Remodel And HD Item Models (optional mod)

TriAevum's Forge can apply **Vanilla+ - Link Remodel And HD Item Models**,
version 1.9, by **HugAMuffin**, to the user's own game data:
<https://gamebanana.com/mods/705890>.

Credits, as published on the mod page:

TriAevum does not distribute the mod. Its packages contain no file of it and
no converted or derived file. On the user's request, Forge downloads the
author's original archive `link_remodel_vanilla_plus_1_9.rar` (6,861,936 bytes,
SHA-256 `8b30a15569e5eb680deda6fdd9582929309ad5acd92dcf70fe2bd8effac0398c`)
from the mod page's download, or the user selects a copy downloaded from the
mod page. Forge keeps it only after the size and hash match, extracts its 26
files and verifies each one, then lets the game read them in place of the
native files, on the user's machine only. The extracted files and the overlay
that points the game at them stay in the user's private data folder.
