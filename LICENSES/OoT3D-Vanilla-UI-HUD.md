# OoT3D Vanilla UI/HUD (optional HD UI texture pack)

TriAevum's Forge can install **OoT3D Vanilla UI/HUD**, version 3.2, by
**chubbycubby**, an HD texture pack for the HUD, the menus and SingleScreen, on
the user's own machine: <https://gamebanana.com/mods/701929>.

TriAevum does not distribute the pack. Its packages contain no file of it and
no converted or derived file; the release audit forbids the archive's and every
texture's SHA-256. On the user's request, Forge downloads the author's original
archive `oot3d_vanilla_ui_hud_32.zip` (451,655,008 bytes, SHA-256
`5ff478db312c3f57f54263cd84f4caef15bbb391fd1dda3bdd3c25c4917938a1`) from the
mod page's download, or the user selects a copy downloaded from the mod page,
or a folder extracted from it. Forge keeps the archive only after the size and
hash match, extracts its 76 textures and verifies each one, and keeps them in
the user's private data folder, sorted by language folder, unchanged. The
pack's `sys8.qbf` is not used.

The original game, its characters and its assets belong to Nintendo; the pack
